# Consulta de Competencias — prototipo interactivo

Demostración estática del flujo público de **Consulta de Competencias**, el servicio de consulta de calificaciones y carné digital de Natural Resources Engineering (NRE).

- No usa datos reales.
- No se conecta a sistemas internos.
- Nombres, cédulas y contratos son de demostración.

Identidad visual tomada del sitio público [nre.com.co](https://nre.com.co/): Prompt, Merriweather, teal `#52A4B1`, amarillo `#F9C01A`, verde `#83BD47` y navy `#212631`.

## Abrir

Sirve esta carpeta como sitio estático (GitHub Pages o cualquier hosting). El archivo de entrada es `index.html`.
